# วิเคราะห์ข้อมูลวิจัย (บทที่ 5)

อ่าน CSV ที่ดาวน์โหลดจากหน้าแอดมิน แล้วสร้างตาราง กราฟ และประโยคสรุปผลสำหรับเขียนบทที่ 5 ไม่ต้องติดตั้งอะไรเพิ่ม ใช้ Node ที่มีอยู่แล้ว

## ขั้นตอน

1. หน้าแอดมิน → ดาวน์โหลดข้อมูลวิจัย 4 ไฟล์: ผู้ใช้ (users), รายวัน (days), รอบอ่าน (sessions), การทบทวน (reviews)
   - ไม่ต้องใช้ไฟล์ "ตารางรหัสผู้ใช้" (user-key) เพราะมีชื่อ/อีเมล
   - ข้อมูลรวมเฉพาะผู้ที่กดยินยอมให้ใช้ข้อมูล ถ้ายังมีคนไม่ได้กด ให้ไปกดยินยอมก่อนดาวน์โหลด
2. ใส่ไฟล์ทั้ง 4 ไว้ใน `BACKEND/scripts/analysis/data/` (โฟลเดอร์นี้อยู่ใน .gitignore ข้อมูลจะไม่หลุดขึ้น GitHub) ใช้ชื่อไฟล์ตามที่ดาวน์โหลดมา ถ้ามีหลายวันสคริปต์จะใช้ไฟล์ล่าสุด
3. รันจากโฟลเดอร์ BACKEND:

```bash
node scripts/analysis/analyze.js scripts/analysis/data
```

ผลจะอยู่ใน `scripts/analysis/data/analysis-<วันเวลา>/`:

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `report.html` | เปิดในเบราว์เซอร์ อ่านผลทั้งหมด คัดลอกตารางไปวางใน Word ได้ |
| `tables/*.csv` | ตารางเดียวกัน เปิดใน Excel ได้ |
| `figures/*.svg` | กราฟ แทรกใน Word ได้ตรงๆ (แทรก → รูปภาพ) ใช้ฟอนต์ TH SarabunPSK |

เลขตาราง/ภาพในรายงานเรียง 1, 2, 3… ต้องเปลี่ยนเป็นเลขตามเล่มเอง

## สิ่งที่วิเคราะห์

| หัวข้อ | ข้อมูลที่ใช้ | สถิติ |
|---|---|---|
| 1. ข้อมูลทั่วไป + การกลับมาใช้งาน | users, days | Mean, SD, Median, Q1–Q3, ร้อยละที่เข้าใช้วันที่ 1/3/7/14/30 หลังสมัคร |
| 2. คะแนนก่อน/หลังอ่าน | sessions (ชุดแรกของแต่ละบท) | Wilcoxon signed-rank (ผลหลัก), paired t-test (ไว้เทียบ), normalized gain ของ Hake |
| 3. ดูแลน้องหมา ↔ การอ่าน | users, days | Spearman (ระหว่างบุคคล), Wilcoxon วันที่ดูแล vs ไม่ได้ดูแล (ภายในบุคคล) |
| 4. ถาม AI ↔ การอ่าน | sessions | Mann-Whitney U + Fisher's exact (ระดับรอบอ่าน), Wilcoxon ภายในบุคคล (ผลหลัก) |
| 5. ปัจจัยที่สัมพันธ์กับผลการเรียน | users | Spearman |
| 6. การทบทวนแบบเว้นระยะ | reviews | ร้อยละที่ตอบถูกเมื่อเว้น 1/3/7/14 วัน |
| 7. ช่วงเวลาการอ่าน | sessions | ความถี่ตามชั่วโมงและวันในสัปดาห์ |

## การอ่านค่า

- **p** สองทาง `*` p < .05, `**` p < .01 ค่า p ของ Wilcoxon และ Mann-Whitney เป็นแบบแม่นตรง (exact, คิดค่าซ้ำด้วย) เมื่อข้อมูลไม่มาก ถ้าข้อมูลมากใช้การประมาณด้วยโค้งปกติ
  - ค่า p แบบแม่นตรงอาจต่างจาก SPSS เล็กน้อย เพราะ SPSS ใช้การประมาณด้วยโค้งปกติเป็นค่าเริ่มต้น
- **r** (rank-biserial correlation) คือขนาดอิทธิพล: < .1 เล็กมาก, .1–.3 เล็ก, .3–.5 ปานกลาง, ≥ .5 ใหญ่
- **rs** (Spearman): < .1 แทบไม่มี, .1–.3 ต่ำ, .3–.5 ปานกลาง, ≥ .5 สูง
- **<g>** normalized gain: < .3 ต่ำ, .3–.7 ปานกลาง, ≥ .7 สูง

## ข้อควรรู้

- **จำนวนคนขั้นต่ำ:** Wilcoxon แบบแม่นตรงต้องมีอย่างน้อย 6 คู่ (ที่ผลต่างไม่เป็น 0) จึงจะมีโอกาสได้ p < .05 ถ้าน้อยกว่านี้ให้รายงานเชิงพรรณนา
- **ความสัมพันธ์ ≠ สาเหตุ:** โดยเฉพาะการดูแลน้องหมา เพราะอ่านจบรอบแล้วน้องหมาได้ความสุข คนจึงอาจไปดูน้องหมาหลังอ่าน
- **ทดสอบหลายคู่:** ตารางสหสัมพันธ์ทดสอบหลายคู่พร้อมกัน ค่า p ที่ใกล้ .05 อาจเกิดโดยบังเอิญ
- `stats.js` ตรวจเทียบกับ scipy.stats แล้ว (spearmanr, wilcoxon, mannwhitneyu, fisher_exact, ttest_rel) กรณีที่มีค่าซ้ำตรวจเทียบกับการเรียงสับเปลี่ยนแบบนับครบทุกกรณี
